# Mesh 模型库与确认后网格化

目标：收藏下方新增「Mesh 模型」，使用与我的作品一致的卡片列表。高斯完成后先标定，允许清理并保存版本；用户确认当前版本后手动生成 Mesh。完成结果自动入库，可预览、下载并回到来源高斯。沿用 5174 的同一套后端、数据库和存储。

1. 新增持久 MeshModel 及迁移，包含所有者、来源作品/不可变版本/任务、算法、单位、几何计数、校验和与私有存储键。提供鉴权列表、详情、文件接口及搜索分页。网格完成时与任务状态一起入库；历史结果按其来源版本独立保留。
2. 接通确认后的几何版本：沿已完成编辑会话追溯标定和原重建资料，将当前已发布高斯导出到原相机坐标，网格化使用该几何而非旧检查点。原始未清理的标定版本仍可复用检查点。保留版本竞态、取消、所有权和路径约束。
3. 新增 Mesh 列表、详情预览和导航；Edit 网格入口说明阶段，确认当前已保存版本后才提交。高斯编辑发布成功后提供进入网格流程的按钮。完成状态链接到 Mesh 模型库。
4. 回填当前环境已经完成的网格，包括此前两份全量 30,000 次结果；准确保留未标定坐标单位，不能冒充米制。仅新增模型库记录和私有文件副本，不切换原作品版本。
5. 使用隔离数据库测试权限、持久入库、编辑溯源、版本和取消竞态；检查前端状态、确认步骤、构建、类型与 lint。真实浏览器验收导航、列表、完整预览/下载、手动提交入库，并核对原 building 和环境。

风险：不能将编辑后的模型静默替换回旧训练几何；不能用标定前的相机直接渲染米制几何。显式记录使用的几何版本、原始相机坐标转换及倍率，并独立检验输出。Mesh 结果与来源版本绑定，生成时版本变化要取消；已完成的独立结果不伪装成后续版本的新结果。
