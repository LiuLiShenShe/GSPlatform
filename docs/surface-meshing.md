# 照片、提示词、真实尺度与表面网格

当前服务入口为 `http://localhost:5174`。登录后进入 `/compute`（侧栏「免费计算」）；`/upload` 用于已有高斯文件，不是照片重建。

1. 选择多视角照片，等待全部上传完成，点击「下一步：参数确认」。
2. 选择「通用重建（gsplat / 3DGS）」或「薄物体、植株重建（2DGS）」。选择「提示词目标重建」，填写要保留的目标，例如 `potted plant; blue cube`。需要尺度标定时必须保留标定物。
3. 选择标准或高精度质量，均为 30,000 次迭代；草稿是 1,200 次预览。勾选素材权利确认，点击「提交计算」。
4. 当前阶段、整体进度和分割预览每 2 秒读取后台任务；训练进度来自实际迭代。COLMAP、融合及 NKSR 求解等阶段没有连续可靠的百分比，会停留在阶段起点直至该阶段完成，不显示虚构的倒计时。刷新页面可恢复重建任务。
5. 成功发布后自动进入 `/model/edit/<作品标识>`。需要时点「模型取景」把模型移入视野；此操作不保存编辑。先读取标定物在模型中的长度，在「尺度标定」输入同一条边的真实长度。整体自动缩放并发布；完成后再保存视角和其他编辑。
6. Edit 顶部点击「表面网格化」→「生成表面网格」。2DGS 自动使用原生 TSDF；3DGS 自动使用 NKSR。该任务同样每 2 秒刷新、可取消、刷新页面可恢复。完成后下载彩色 PLY 三角网格，单位为米。

## 几何与尺度约束

网格从该次重建保留的最终检查点及相机生成，不从碰撞代理提取。原始训练坐标在网格输出时乘同一份标定证据中的倍率一次，避免重复缩放。视角和标注不会改变几何版本；如果 Gaussian 编辑发布了新几何，原深度已经不对应，接口拒绝生成或下载旧网格。场景展示层的世界变换不写入网格。

只有拥有原始训练资料、且已完成自动尺度标定的照片重建结果可使用此入口。以前直接导入的高斯（例如 building）仍可查看和编辑，但缺少相机/原生检查点时不会伪造重建来源。标定数值由用户提供，不等于计量精度认证。网格的几何精度仍依赖照片覆盖、分割和重建质量。

## 运行环境

API 与所有 worker 复用同一配置。提示词分割设置 `GS_SAM3_SOURCE`、`GS_SAM3_PYTHON`、`GS_SAM3_CHECKPOINT`。2DGS 设置 `GS_2DGS_REPO` / `GS_2DGS_PYTHON`，默认复用本机已有仓库。

3DGS 使用 gsplat 的 `RGB+ED` 渲染最终训练模型，按原相机去畸变并应用提示词掩膜；从有效深度有限差分得到朝向观察相机的法线，再交给 NKSR。最多采样 150,000 个有向表面观测；NKSR 体素为稳健表面范围的 1/256，使用 ks 预训练权重和原求解设置。2DGS 使用本地 `GaussianExtractor` 的有界 TSDF 默认参数：分辨率 1024、深度范围为相机半径两倍、截断距离为体素五倍，保留最多 50 个组件。

NKSR 设置 `GS_NKSR_PYTHON` 与 `GS_NKSR_WEIGHTS`，只接受运维配置，不接受请求传入路径。本机复用已有独立 `.venv-nksr` 和 `nksr_ks.pth`；该环境包含既有 ATen 向量运算兼容补丁，不修改研究仓库或训练算法。新部署需先安装并验证这些可选环境；能力接口的 `tools.sam3` / `tools.nksr` 表示路径已配置，实际执行由子进程进一步检验。

`BUILD_MESH` 在 GPU 队列执行，具有执行代次、租约、取消和版本检查。文件保存在私有 `storage/meshes/<scene>/<job>`；拥有者下载接口始终重新检查权限和当前几何。结果包含方法、顶点/面数、倍率、米制包围盒及 SHA256。异常保留原高斯作品。

上游依据：[2DGS](https://github.com/hbb1/2d-gaussian-splatting)、[gsplat 深度渲染](https://github.com/nerfstudio-project/gsplat/blob/main/docs/source/migration/migration_legacy.rst)、[NKSR](https://github.com/nv-tlabs/NKSR)。本机验收见 `docs/reports/GS_MESH_07_ACCEPTANCE.md`。
